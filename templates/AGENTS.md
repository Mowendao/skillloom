# 工作区文件规范（始终生效）

本工作区遵循 `workspace-organizer` skill 的文件规范。任何创建、修改、移动、删除、导出、下载、整理文件的任务，先加载该 skill，并遵守以下底线：

1. **分区**：文件只放 `NN_<主题>/` 或 `99_临时与杂项/`；根目录不留散落文件（`README.md`、`AGENTS.md`、`CLAUDE.md`、`整理说明.md` 除外）。
2. **角色目录**：输入放 `<主题>/_输入/`（只读），产出放 `<主题>/_产出/`，旧版本放 `<主题>/_归档/`，临时文件放 `99_临时与杂项/tmp/<task-id>/`。
3. **产出命名**：`YYYY-MM-DD_<主题>_<描述>_v<N>.<ext>`；代码/项目遵循项目自身命名。
4. **不覆盖**：目标已存在时，同内容复用，不同内容递增版本或归档；绝不覆盖。
5. **不删除**：用户文件永不删除；删除请求先移到 `99_临时与杂项/归档/待删除/` 并确认。只删除自己创建且记录在案的临时文件。
6. **边界**：不进入 `.git`、`.dsh`、`.dsh-im`、`.agents`、`.acl-recovery`、`node_modules`、`.venv`、`dist`、`build` 等受保护目录；不跨出工作区根目录。
7. **自检**：写入前运行 `preflight.ps1`，任务结束前运行 `audit.ps1`；`ok=true` 或已逐条说明例外之前，不得声称完成，违规按 skill 第 4.3 节修正。

用户明确说「保持原样/不要整理」时，以用户指令为准。批量移动多个顶层条目、重命名现有目录前，必须先给方案并得到确认。
