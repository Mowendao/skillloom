# five-stage-learning

按斯科特·杨的五阶段「获取 → 理解 → 扩展 → 应用 ↔ 纠错」，在 DSH 里带用户学一个具体知识点。

- 每次只推进**一个**阶段，用「出口条件」判断能不能进下一阶段，不用时间判断。
- 主线 1→2→3→4；纠错是回边，只由第 4 阶段失败触发。
- 最短闭环 = 1→2→4（小知识点可跳过扩展）。
- **没有第 4 阶段的产出，不算学完。**

## 何时使用

- 想系统学一个具体知识点，而不是要一份资料汇总；
- 说「用五阶段带我学 X」「五阶段学 X」；
- 学完想验证是不是真会了（需要可判定的产出与错误记录）。

## 五个阶段

| 阶段 | 目标 | 出口条件 |
|---|---|---|
| 1 获取 | 拿到最小可理解单元（≤3 个来源或 1 章），不做摘要 | 能一句话说清「要解决什么问题」，手上有一份能动手的材料 |
| 2 理解 | 合上材料用自己的话复述，找一个类比，标出还没想通的那句 | 复述无硬错、类比自洽、含糊点 ≤1；概念型加费曼测试，行话超 2 次不算过 |
| 3 扩展 | 连问三层「为什么」，做一个跨领域同构，写出失效边界 | 至少两层「为什么」+ 一条有效同构（三要素对应 + 一处断裂），或给出「找不到同构」的具体理由 |
| 4 应用 | 闭卷限时产出可判定的东西：做题 / 讲给外行 / 写决策理由 | 留下一次可判定的产出记录 |
| 5 纠错 | 错误归类、定重测时间（48 小时或 7 天）、回灌上游 | 错误已归类且有重测日期 |

## 先分清知识类型

不同知识用不同尺子，别用错：

| 类型 | 判据 | 主要验证方式 |
|---|---|---|
| 概念型 | 为什么成立、边界在哪 | 费曼讲解（第 2、4 阶段） |
| 程序型 | 能不能按步骤做对 | 闭卷做题 / 写代码（第 4 阶段） |
| 判断型 | 该不该、选哪个 | 写决策理由，让反对者来驳（第 4 阶段） |

## 在 DSH 里怎么用

```text
用五阶段带我学 <知识点>
```

进到某个阶段后，可以直接用 `SKILL.md` 里给的提问模板，例如：

- 「帮我用 3 句话划出 X 的边界：解决什么问题，不解决什么问题。」
- 「这是我的复述，只挑错和含糊的地方，不要重写我的句子。」
- 「基于我刚学的 X，出 1 道 5 分钟能做完的题，先不给答案。」
- 「我只记得这个错法，帮我归类：是概念、边界还是步骤问题？」

## 落盘

每轮产出写进 `09_Obsidian\20_Notes\`，用笔记模板的三栏（问题 / 我的答案 / 验证方式）；错误记在「验证方式」里，复发标 `复发×2`。写文件前先给 diff。

## 安装

```powershell
Copy-Item -Recurse .\skills\five-stage-learning "$env:DSH_HOME\skills\five-stage-learning"
```
